Welcome to Geographical Adventures ♥

This is a fan-made web port of Geographical Adventures, a lovely little geography game by Sebastian Lague.

It exists for one simple reason: so that anyone can experience this amazing game right here, in the browser, on any computer — no downloads, no setup, no Unity required.

Absolutely everything belongs to Sebastian Lague — the game, its design, its art and its code are all his. This port is only a loving re-implementation built on top of his open-source work. None of the credit is ours; all of it is his.

If it brings you even a little bit of joy, please support him and check out the original:

Play the original on itch.io Source code on GitHub Watch the dev series on YouTube

Thank you, Sebastian. ♥
